# 角色动画皮肤

## 当前实现

收藏馆采用顶部分类、左侧角色、中间皮肤网格、右侧试穿详情。购买、装备、等级解锁及恢复原版沿用成长系统逻辑。
现有角色皮肤为星轨魔导书、雷霆小机甲、云游茶壶、翡翠星使、星轨术士、霜晶骑士、花火游侠，使用 SpriteKit 场景部件和 SKS 资源。

## 退役皮肤兼容

软糖派对（party）、像素方块（pixel）、竹筒小侠（bamboo）、弹弹蛋（egg）、方块工匠（voxel）、萤火精灵（firefly）已退役。
对应目录、序列帧、专用生成器及 CharacterSkinEffects 手写特效已移除。读取旧档案时清除这些皮肤的装备引用，恢复原版；保留积分、经验、拥有记录和其他装备。

本目录既有 comparison/runtime 图片、动图属于历史设计记录，不代表当前可用皮肤；当前目录以 `cosmetics.json` 为准。

## 后续特效约定

后续新增或重做特效统一使用 `.sks`，通过 `FXLibrary` 加载与复用，代码负责事件、参数和生命周期；不再新增手写粒子或逐帧生成器作为特效主体。详细约定见根目录 `AGENTS.md`。其他现有非皮肤特效不随本次清理迁移。

## 验证

Swift 测试覆盖六款退役皮肤的目录移除与旧档回退、其他装备隔离、原版动画回退、剩余 SKS 皮肤的资源与战斗行为。原始植物与僵尸素材来源见 `Packages/LearnKit/Sources/LearnGame/Resources/Sprites/SOURCE.md`。
