# 森林怪物移动与攻击序列

## 来源与处理

- 生成日期：2026-11-10。
- 工具：Codex 内置 `imagegen`，每张图集以对应原有 `ForestRoster/<kind>.webp` 为角色参考。
- 原始图集：各单位的 `source.png`，1536 或 1254 像素见方、透明背景。
- 游戏成品：`Sprites/ForestActions/<kind>-action-0.webp` 至 `-8.webp`，320×320、朝右、落脚点 y=280。
- 处理脚本：`python3 scripts/import-forest-actions.py`。只切图、清低 alpha、统一缩放与锚点；参数和源图边界写入 `Sprites/ForestActions/manifest.json`。
- 原始图集和提示词保留在文档目录，不进入 App；99 张成品总计约 3.4 MB。

## 帧约定

每张图集为 3×3：

0–5：无缝移动循环。普通地面单位交替迈步；史莱姆用蠕动波；冥魂收割者和石像鬼用翼振/悬浮。

6：攻击蓄力。

7：出手伸展。

8：收招恢复。

大型爆炸、斩击、冰片、毒液和灵魂拖尾没有烘焙进角色，而由 `ForestCombatOverlay` 在实际弹道命中后分六阶段绘制。骷髅和野猪沿用已有六帧移动素材，施法时增加压低、前冲和向目标转身的程序化动作。

动作位图只在单位进场时预热该单位的九帧，缓存最多保留 27 帧；未遇到的首领不会占用动作位图内存。

## 生成约束

每次生成都固定以下约束：保持原角色的服装、武器、配色、头身比例和绘制风格；3×3 等大格子；统一朝右三视角；透明背景；不出现文字、网格、地面阴影或大范围烘焙特效；角色和武器不跨格；移动帧必须真实交替肢体；攻击帧分成蓄力、出手、收招；所有单位共享相对放大和脚底/悬浮基线。

各单位只改变动作语义：

- `knight`：盾牌保持稳固，肩后蓄力，向前挥剑。
- `goblin`：低持弹弓行走，拉弓、释放、回收。
- `acolyte`：袍下双脚迈步，聚球、伸臂施法。
- `berserker`：双斧行走，交叉蓄势、双臂横斩。
- `frostKing`：重步逼近，冰爪后拉、前刺。
- `infernal`：三叉戟行走，举戟、突刺。
- `pharaoh`：木乃伊僵硬交替步，绿焰手蓄力、前伸。
- `reaper`：不迈腿，六段翼振与袍尾漂移；镰刀后撤、横扫。
- `slime`：没有腿，六段蠕动挤压；蓄力后从口部喷吐。
- `gargoyle`：不迈腿，六段强翼振；双爪蓄力、向目标抓击。
- `shaman`：持颅骨法杖行走；药瓶手收回、投掷、恢复。

## 验证要求

自动化检查覆盖每单位九帧存在且内容不同、320×320 尺寸、行走与攻击阶段选择、定身冻结、浮空单位使用翼振帧、六段命中特效边界。素材仍需要在 iPad 实际尺寸和真机 GPU 环境下检查循环速度、轮廓可读性及视觉舒适度。
