# 防御道具：拦住僵尸，多给孩子答题时间

## 目标

射手都是"答对 → 发射"。孩子答得慢时，原来只能看着僵尸逼近——僵尸会直接穿过植物，走到书架才结算。

防御道具只做一件事：**让僵尸停下来，换来答题时间**。规则要让幼儿园孩子一眼看懂：

- 挡住 → 僵尸在它前面停下来"啃"；
- 啃坏了 → 道具碎掉，格子空出来，僵尸接着走；
- 炸到 → 僵尸直接倒下。

## 道具

| id | 名字 | 阳光 | 怎么用 | 作用 | 素材 |
|---|---|---|---|---|---|
| `wallnut` | 坚果墙 | 50 | 拖到草坪 | 挡住僵尸，被啃够耐久秒数后碎掉 | pypvz `WallNut`，两档裂纹 |
| `tallnut` | 高坚果 | 125 | 拖到草坪（仅小学） | 同上，更耐啃；路障僵尸跳不过去 | pypvz `TallNut`，两档裂纹 |
| `potato` | 土豆雷 | 25 | 拖到草坪 | 种下后答对 N 题才出土；出土后第一个踩上的僵尸倒下 | pypvz `PotatoMine`（埋土、待机、爆炸） |
| `ironGate` | 铁栅门 | 75 | 战斗中点卡牌（仅小学） | 落在**正在答题的僵尸**面前把它挡住；场上同时只有一道，碎了才能再放 | 矢量画 |

### 为什么用阳光购买，不靠击杀掉落

- **最需要的孩子拿得到**：掉落按击杀算，答得慢的孩子击杀少、掉落也少，和"给慢的孩子争取时间"正好相反。
- **规则确定**：卡片标着价格，阳光够就能用；掉落是概率，关键时刻不一定有。
- **学习闭环**：答对 → 打倒僵尸 → 得阳光 → 买道具 → 多了答题时间，奖励的是答对而不是运气。
- **战斗中的阳光有了用处**。
- 冰冻符、幸运星、爱心叶仍然靠击杀掉落，作为惊喜奖励。

## 规则

| 情况 | 规则 |
|---|---|
| 碰撞 | 僵尸和防御道具中心相距半格（`contactGap`）时停下，在道具面前啃 |
| 耐久 | 按秒算：每帧减少 `dt × speedFactor × 僵尸减速倍数`。冻住的不啃，减速的啃得慢，几只一起啃消耗叠加 |
| 裂纹 | 剩 2/3、1/3 时换裂纹帧；没有序列帧的画裂缝 |
| 碎掉 | 移除道具、空出格子；正在啃的僵尸接着走 |
| 被挡住时答错 | 不往前冲，改为狠咬一口：扣 2 秒耐久（`GameScene.wrongAnswerBite`） |
| 被挡住时答对 | 照常挨打；大喷菇击退会把僵尸推离道具，走回来后再次被挡 |
| 路障僵尸（走法 `.hop`） | 小学能跳过坚果墙，跳不过高坚果和铁栅门；幼儿园不跳（`wallsCanBeVaulted`） |
| 土豆雷出土 | 种下后每答对一题算一次（不论是否第一次就答对），够数后出土 |
| 土豆雷爆炸 | 普通僵尸（含两滴血的铁桶僵尸）直接倒下，按击败结算阳光和掉落；首领只扣 1 滴血并被弹开 |
| 发射 | 防御道具不发射。`fire` / `canAttack` 只看射手；只种了防御道具的路，答对时提示先种字灵 |
| 开始闯关 | 至少一路有射手才能开始，只种防御道具不算布阵 |
| 种植时机 | 和射手一样，准备阶段、战斗中、回合休息时都能拖卡种植 |

## 数值

| 年级与难度 | 坚果墙 | 高坚果 | 土豆雷出土 | 铁栅门 |
|---|---|---|---|---|
| 幼儿园（三档） | 20 秒 | 不提供 | 答对 1 题 | 不提供 |
| 小学入门、标准 | 15 秒 | 30 秒 | 答对 2 题 | 10 秒 |
| 小学挑战 | 12 秒 | 25 秒 | 答对 3 题 | 8 秒 |

参照：小学标准一只僵尸走完全程 22 秒、每 5.5 秒出一只，一颗坚果墙大约多给 2～3 只僵尸的答题时间。幼儿园不会失败（僵尸到书架只退回起点），所以只给坚果墙和土豆雷，也不让僵尸跳墙，免得孩子看不懂为什么没挡住。

## 测试

`Tests/LearnGameTests/GuardTests.swift` 覆盖：坚果墙挡住并被啃碎、冻住不啃、两只一起啃消耗翻倍、路障僵尸跳矮墙、防御道具不发射、土豆雷出土前不触发且出土后炸倒、首领只扣血、答错狠咬、铁栅门落点与耐久、裂纹和出土换帧、对局里扣阳光和限制一道门、幼儿园不提供铁栅门。`LearnCoreTests` 检查各难度的数值。

设置 `GUARD_PREVIEW=<png 路径>` 运行 `exportGuardPreview` 可导出一张布阵截图目检。
