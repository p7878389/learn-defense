# 设置页（家长专区）UI 设计稿

家长用的「⚙️ 设置」页：朗读语音、课本与题库（导入课本）、数据与备份（重置所有数据）等，以及进入设置前的家长验证。尺寸和 `docs/ui-growth` 一致：11 寸 iPad 横屏 1194×834 pt，PNG 为 @2x。

| 文件 | 内容 |
|---|---|
| `01-stitch-设置-朗读语音` | 设置页框架 + 「🔊 朗读语音」分区：朗读方式（iPad 系统语音 / 豆包 / 讯飞，两家云端同时选中时显示权重比例条），「高级设置（音色·权重）›」进入 `docs/ui-tts` 的详细页；语速、音调、音量滑块；试读；三个朗读开关 |
| `02-stitch-课本与题库` | 「📚 课本与题库」：导入课本（从文件 App 选择 / 怎么做题库），已安装课本列表——导入的可删除、覆盖了内置的有橙色标签，内置的不能删 |
| `03-stitch-导入课本确认` | 选好 JSON 文件后的确认面板：书名、版本、年级、册；单元 / 课 / 生字 / 词语 / 古诗 / 成语数量；同名课本替换提示（学习记录保留）；格式检查结果；「再想想」/「导入并替换」 |
| `04-数据与备份` | 「💾 数据与备份」：存储空间、导出 / 恢复备份、重置单个孩子（只清学习记录，保留档案）、危险区「重置所有数据」 |
| `05-stitch-重置确认` | 点「重置所有数据」后的二次确认：列出会被删除的内容，默认勾选「保留我导入的课本」，提示先备份，输入「重置」两个字，再按住按钮 3 秒才执行 |
| `06-stitch-家长验证` | 首页点「家长专区」时先答一道乘法题（四选一），答对才进入设置；每次换题，连续答错 3 次等 1 分钟，不显示倒计时 |

## 交互规则

### 入口与家长验证

- 入口是首页右上角的「家长专区」（`docs/ui-home` 里已规划）。点了先出 06，答对进入设置，默认打开「朗读语音」。
- 题目用两位数以内的乘法，4 个选项样式完全一样。连续答错 3 次后 1 分钟内不能再答。
- 「退出家长模式」回到首页；下次进入仍要验证。

### 朗读语音（01）

- 朗读方式：只选系统语音时不联网；选了豆包或讯飞（可两家都选）时按权重挑一家，失败自动换另一家，都不可用时退回系统语音。详细的账号、音色、权重在 `docs/ui-tts`。
- 语速默认 0.42、音调默认 1.1（对应现在 `Speech.speak` 里的 `rate`、`pitchMultiplier`）。
- 「静音模式下也朗读」对应现在 `Speech.init` 里设置的 `.playback` 音频类别，现在是固定开启的。

### 导入课本（02、03）

- 「从文件 App 选择」打开系统文件选择器，只允许 `.json`。选好后先解析和校验，再出 03 的确认面板；不合格时面板改为红色错误列表（如「第 3 单元第 2 课：pinyin 不能写成 chen2」），只有「知道了」按钮——这个状态没出稿。
- 导入就是把文件复制到 `Documents/Packs`（`AppPaths.userPacksDirectory`），和现在「文件 App 里放文件」是同一个目录，所以两个入口效果一样。导入后立即重新加载题库，不用重启 App（现在需要重启）。
- 同 `id` 的课本：导入的替换导入的、导入的覆盖内置的（现有规则），03 里提示「会替换它」。学习记录按素材记，替换课本不会丢。
- 列表里的统计数字（单元、字词数）从题库 JSON 里数出来。
- 「删除」只删导入的文件；删除覆盖了内置的课本后，内置版本重新出现。删除要二次确认。
- 「怎么做题库？」打开 `docs/题库格式.md` 的内容（App 内置一份简化说明）。

### 数据与备份（04、05）

- 导出备份：把 `profiles.json` 和 `progress/*.json` 打包成一个文件，用系统分享面板保存或发送。恢复：选备份文件，确认后替换全部档案和记录。
- 重置单个孩子：清空这个孩子的学习记录文件（`progress/<id>.json`），档案保留。点了要二次确认（简单弹窗，没出稿）。
- 重置所有数据（05）：删除 `profiles.json`、`progress/` 目录和所有设置；勾选「保留我导入的课本」时不动 `Documents/Packs`，不勾选时一起删。完成后回到首页的空状态（`docs/ui-home` 的 07）。
- 05 的两道保险：输入框内容等于「重置」后，红色按钮才可按；按住 3 秒、进度条走满才执行，中途松手取消。

## 和现有功能的差距（落地前要决定）

- 设置页、家长验证、家长专区入口现在都不存在。
- 导入、删除课本、导出 / 恢复备份、重置数据、清理图片缓存都需要新写；`ContentLibrary` 现在只在启动时读题库，要支持重新加载。
- 「孩子档案」「声音与游戏」「关于」三个分区只有导航项，没出稿。「声音与游戏」打算放：背景音乐 / 音效音量、答题时间、僵尸速度、护眼休息提醒、左手模式；其中大部分对应的功能现在也没有。
- 等级、积分、徽章、外观来自成长系统（`docs/ui-growth`），没做成长系统前重置清单里去掉这几项。

## 稿件之间的不一致（落地时统一）

- 01、02 的顶栏和侧栏是一套（圆形返回按钮、侧栏宽 280px），03、05 的背景是 Stitch 另画的简化版（胶囊返回按钮、侧栏更窄），以 01 为准。04 由 05 的背景改出来，所以也是简化版。
- 侧栏底部的小卡片每张写的都不一样（01「护眼与安全防护 · 健康使用时长 30 分钟」是 Stitch 自己加的，没有这个功能），统一成「档案和学习记录只保存在这台 iPad 上」或去掉。
- 01 朗读方式卡上的「智能容灾 · 毫秒响应」「自然温润 · 萌趣童音」等宣传语、「童声小萌」音色名、03 的 26 课 / 280 生字等数字都是示意。
