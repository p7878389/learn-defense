# 角色、道具与特效：结构和扩展方法

怪物、字灵、道具都由**可替换的部件**组合而成。新增一种角色，大多数时候只需要把已有部件重新搭配一下，写一个定义即可；只有需要全新的玩法时，才要新写一个部件。

内置角色现在采用植物与僵尸序列帧，ID 和玩法保持兼容。`UnitSprites` 按 `plant-<id>` / `zombie-<id>` 加载资源，缓存并共享纹理，以共同包围盒去掉透明留白、保持纵横比。未知 ID 或缺帧时仍使用原有 `EnemyArt` / `DefenderArt` 矢量组合。图片来源和导入方法见 `Sources/LearnGame/Resources/Sprites/SOURCE.md`（相对 `Packages/LearnKit`）。

## 用到的设计模式

| 可复用的东西 | 模式 | 配置（LearnCore，纯数据） | 实现（LearnGame） |
|---|---|---|---|
| 怪物、字灵、道具本身 | 组合 | `EnemyKind` / `DefenderKind` / `ItemKind` 把部件组合在一起 | — |
| 怪物走法 | 策略 | `MovementStyle`：匀速、跳跃、时快时慢 | `MovementStrategy`，放在 LearnCore，可以单元测试 |
| 字灵攻击方式 | 策略 | `AttackStyle`：单发、连发、光束 | `AttackStrategy`：`ShotAttack`、`BeamAttack` |
| 命中效果 | 策略 | `HitEffect`：击退、减速整条路 | `HitEffectStrategy`：`KnockbackHit`、`SlowLaneHit` |
| 视觉特效 | 策略 | `DefeatEffect`：墨点、涟漪、星星 | `VisualEffect`：墨点四散、涟漪、星星、全屏闪光、飘字、雪花 |
| 道具效果 | 命令 | `ItemEffect`：清场、冻住全场、回血、加分 | `ItemCommand`，在 `Battlefield` 接口上执行 |
| 战场背景 | 组合 + 配置 | `SceneTheme`：天空、远景、路面、装饰、飘过的东西、基地 | `Backdrop` 按层画出来 |
| 3D 图片 | 门面 + 缓存，缺图时退回 emoji | 所有图案都用 emoji 表示 | `Pictures` / `PictureView`，有图用图，没图画 emoji |
| 外观 | 资源缓存 + 组合回退 | 内置角色 ID；`EnemyLook` / `DefenderLook` / `ProjectileLook` | `UnitSprites` 序列帧，缺图时使用 `EnemyArt` / `DefenderArt` / `ProjectileArt` |
| 配置 → 策略 | 简单工厂 | 每个配置枚举都有 `makeStrategy()` / `makeEffect()` / `makeCommand()` | — |
| 查找 | 注册表 | `UnitCatalog.enemies / defenders / items` | — |
| 一局出哪些怪、用哪些字灵 | 数据驱动 | `GameTuning` 里的 `waves`（`WavePlan`）、`lineup`、`ultimate` | — |

**配置和实现分开放：**

- 配置是 LearnCore 里的纯数据，不依赖画面，可以在 Mac 上直接测试，以后也能改成从 JSON 读取。
- 实现放在 LearnGame。

**场景和对局逻辑只认接口，不认具体种类：**

- `GameScene` 和 `GameSession` 只调用 `AttackStrategy`、`HitEffectStrategy`、`VisualEffect` 和 `ItemCommand` 这几个接口。
- 代码里没有任何类似 `if 怪物 == 铁头墨` 的分支。

**道具**

## 怎么扩展

**1. 用已有部件组合一种新怪物**（最常见，只改一个文件）

```swift
// UnitCatalog.swift
static let ghost = EnemyKind(
    id: "ghost", name: "飘飘墨", hp: 1, speed: 1.2,
    movement: .surge(period: 2, amplitude: 0.5),
    look: EnemyLook(body: .cloud, color: .plum, accessory: .horns, eyes: .single, defeat: .ripple),
    drop: ItemDrop(.luckyStar, chance: 0.3))
```

然后做两件事：

- 把它加进 `UnitCatalog.enemies`；
- 在 `Difficulty.swift` 某个难度的 `WavePlan(mix:)` 里给它一个权重。

字灵和道具也是同样的做法。

**2. 新增一种部件**（比如新的走法「蛇形走位」）

1. 在 `MovementStyle` 加一个 case，比如 `.zigzag(...)`。
2. 写一个遵循 `MovementStrategy` 的结构体。注意平均速度要等于传入的 `speed`，测试会检查这一点。
3. 在 `makeStrategy()` 里返回它。

其他部件也一样：

| 想新增的部件 | 加 case 的枚举 | 要实现的协议 |
|---|---|---|
| 攻击方式 | `AttackStyle` | `AttackStrategy` |
| 命中效果 | `HitEffect` | `HitEffectStrategy` |
| 道具效果 | `ItemEffect` | `ItemCommand` |
| 退场特效 | `DefeatEffect` | `VisualEffect` |

如果道具效果需要新的战场能力，再给 `Battlefield` 加一个方法。

**3. 新增一种背景主题**（比如「海边」）

1. 在 `SceneTheme.swift` 里写一个 `static let seaside = SceneTheme(...)`，选好天空颜色、远景、装饰的 emoji，再把它加进 `SceneTheme.all`。
2. 在 `Pictures/manifest.txt` 加上新用到的 emoji，运行 `python3 -I scripts/fetch-pictures.py` 下载图片。
3. 在题库单元里写 `"theme": "seaside"`。

**4. 新增一种外观部件**（比如新的配件「眼镜」）

1. 在 `EnemyLook.Accessory` 加 `.glasses`。
2. 在 `EnemyArt.accessory` 里画出来。

以后有了美术图片，也只需要改 `EnemyArt` / `DefenderArt`，把形状换成贴图，别的代码不用动。
