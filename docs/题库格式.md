# 题库格式（schemaVersion 1）

题库是一个个 **JSON 文件**，每个文件叫一个「题库包」，通常对应一册课本（如「三年级上册 语文」）。

- 内置题库：`Packages/LearnKit/Sources/LearnCore/Resources/Packs/*.json`，随 App 一起打包。
- 自己导入：在 iPad「文件」App →「我的 iPad」→「字灵守卫」→ `Packs` 文件夹里放 JSON 文件，重启 App 即可读到。
  与内置题库 `id` 相同时，导入的覆盖内置的。

题库里放的是**知识点素材**（生字、词语、成语、古诗……），而不是一道道写死的题。
App 会根据素材和难度自动出题（看字选拼音、选字填空、成语补全、接下一句等），干扰项也自动生成。
只有特殊题目（如字义辨析）才需要用 `questions` 手写。

## 结构

```text
题库包 ContentPack
└── units 单元（多个）
    └── lessons 课（多个）
        ├── characters  生字
        ├── words       词语
        ├── idioms      成语
        ├── poems       古诗
        ├── pictures    图片词（幼儿园用）
        └── questions   手写选择题
```

课里的各个数组都可以省略，只填有的部分。

## 顶层字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `schemaVersion` | 是 | 固定为 `1` |
| `id` | 是 | 全局唯一，建议 `学科-年级-册-版本`，如 `chinese-g3-up-bubian` |
| `title` | 是 | 显示名称，如 `三年级上册 语文` |
| `subject` | 是 | `chinese` 语文 / `english` 英语 |
| `grade` | 是 | `k2` 中班、`k3` 大班、`g1`～`g6` 一～六年级 |
| `term` | 否 | `up` 上册 / `down` 下册 |
| `edition` | 否 | 教材版本，如 `部编版` |
| `units` | 是 | 单元列表 |

单元：`{ "id": "u1", "title": "第一单元", "theme": "academy", "lessons": [...] }`，课：`{ "id": "l1", "title": "1 大青树下的小学", ... }`。

单元的 `theme` 可省略，用来指定战场背景：

| `theme` | 背景 |
|---|---|
| `meadow` | 草地（适合动物） |
| `orchard` | 果园（适合水果、秋天） |
| `starry` | 星空（适合天空、夜晚） |
| `academy` | 书院 |

一局选了好几个单元时，用出现次数最多的主题。没写 `theme` 的，幼儿园默认用草地，小学默认用书院。
`id` 在同一个题库包内唯一即可。

## 素材类型

### 生字 `characters`

```json
{ "char": "晨", "pinyin": "chén", "words": ["早晨", "晨光"] }
```

- `pinyin` 用**带声调符号**的拼音（`chén`，不要写 `chen2`）；轻声不标调。
- `words` 是组词，可省略；有组词才会出「选字填空」题，也能在「看拼音选字」时给出提示。
- `image_association` 是可选的字形联想文本，例如「像中间流淌的河流。」；幼儿园用于听字谜选字，并从「提手旁、三点水」等关键词挑同部首干扰项。不含答案字且非空才会作为字谜朗读。
- 出题：小学为看字选拼音、看拼音选字、选字填空；幼儿园按掌握度和难度依次尝试听音选字、听词填字、听字谜或声母单空、声母与韵母多空。听词填字只使用目标字出现一次的组词，无法生成时降阶。

### 词语 `words`

```json
{ "text": "早晨", "pinyin": "zǎo chen" }
```

拼音按字用空格分开。出题：看拼音选词语。

### 成语 `idioms`

```json
{ "text": "手舞足蹈", "pinyin": "shǒu wǔ zú dǎo", "meaning": "形容高兴到了极点。" }
```

出题：成语补全（随机挖掉一个字）。大招题优先从成语里出。

### 古诗 `poems`

```json
{ "title": "山行", "author": "杜牧", "dynasty": "唐",
  "lines": ["远上寒山石径斜", "白云生处有人家", "停车坐爱枫林晚", "霜叶红于二月花"] }
```

`lines` 按**句**拆分（逗号、句号处断开），不带标点。出题：给上一句，接下一句。

### 图片词 `pictures`（中班、大班）

```json
{ "text": "猫", "pinyin": "māo", "emoji": "🐱", "en": "cat" }
```

`emoji` 会自动换成对应的 3D 图片（来自 Microsoft Fluent Emoji）。App 里没有这张图时，就直接显示 emoji。
导入新题库后，运行 `python3 -I scripts/fetch-pictures.py`，把题库里用到但还没有的图补下载下来，再重新装一次 App。
出题方式：听读音选图片，孩子不用识字。答对后会弹出单词卡，上面有图、字和拼音。

### 手写选择题 `questions`

```json
{ "id": "q1", "prompt": "“霜叶红于二月花”中“于”的意思是？",
  "options": ["比", "在", "和"], "answer": "比", "explain": "霜叶比二月的花还要红。" }
```

`answer` 必须和 `options` 里的某一项完全一致。

## 英语题库

`subject` 写 `english`。英语教材通常不分课，单词和句子可以直接放在单元下：

```json
{
  "id": "u1",
  "title": "Unit 1 Greetings",
  "theme": "academy",
  "words": [
    { "word": "hello", "phonetic": "/həˈləʊ/", "meaning": "喂；你好" }
  ],
  "sentences": [
    { "sentence": "Good morning, boys and girls!", "meaning": "早上好，孩子们！" }
  ]
}
```

- 读取时单元下的单词、句子合成一课（课 id 为 `l1`，课名用单元名）；也可以照常写 `lessons`，课里用 `englishWords`、`sentences`。
- 单词：`word` 和 `meaning` 必填，`phonetic` 音标可省略。几个意思用「；」隔开；意思里有相同义项的词（如 hello「喂；你好」和 hi「嗨；你好」）不会互相当干扰项。
- 出题：单词随机出「看英文选意思」（有音标时作提示）、「看意思选英文」、「听英文选单词」；句子出「选出句子的意思」。
- 英文用英式发音朗读，中英混排时分段读。
- 学习记录的 key：单词 `en:hello`，句子 `sentence:原句`。同一个词出现在不同版本、不同单元时算同一个知识点。
- `associations`、`phonics` 等其他字段会被忽略，可以保留在文件里。

## 完整示例

见 `Packages/LearnKit/Sources/LearnCore/Resources/Packs/` 下的：

- `chinese-g3-up-pep.json`：三年级上册语文（人教版），8 个单元 26 课
- `chinese-k2-sample.json`：中班语文启蒙示例
- `zhijing-literacy-k2.json`、`zhijing-literacy-k3.json`：直映识字（幼儿园启蒙），分别供中班、大班使用；内容相同，共六册 111 字：第一册「基础与自然」15 字、第二册「姓氏与生活」12 字、第三册「校园与品格」20 字、第四册「动物与生活」21 字、第五册「自然与生活进阶」20 字、第六册「情感与复杂动作」23 字
- `english-g3-up-pep.json`、`english-g3-up-jingtong.json`：三年级上册英语（人教 PEP 版、人教精通版）

直映识字原始数据的 `grade: "kindergarten"` 按年级转换为 `k2` / `k3`，`volumes` 按原册次转换为六个单元，每单元一课。生字里的 `char`、`pinyin`、`words`、`image_association` 用于题阶生成；JSON 中的 `idioms`、`tts_text` 仍是附加资料，App 不使用它们出题。成语不放入课级 `idioms`，以免在幼儿园题库中生成成语补全题。

`image_association` 缺省时仍可正常导入，字谜阶回退到声母题。比如「手」的联想含有「手」字，会回退而不直接读出答案。新增的有效字谜已列入语音清单；发布高质量语音包时需要重新运行 `speech-pack --bundled --game-lines`（见下方语音命令），未生成的语句沿用运行时语音回退。

## 学习记录

每个孩子的答题记录按素材记（如 `char:晨`、`idiom:手舞足蹈`、`poem:山行#0`），和具体题型无关。

幼儿园题阶复用知识点的连续答对次数，不新增进度存储结构。新题型 `listenFillChar`、`shapeRiddle`、`pictureToWord` 会写入对局记录；包含这些记录的备份需用支持这些题型的新版 App 恢复，旧版 App 无法解析。旧题库和旧备份仍可由新版读取。
所以同一个字，不管是看字选拼音答错，还是选字填空答错，都会进入错题本，之后更频繁地出现，
连续答对 2 次以上才从「待复习」里移出。修改题库素材的内容不会丢记录，但改了 `char`/`text`/诗题会被当成新素材。

## 本地数据库

App 用 SwiftData（底层 SQLite）在 Application Support 下的 `LearnDefense/learn.store` 存数据，代码见 `LearnCore/Storage/`：

| 表 | 内容 | 来源 |
|---|---|---|
| `StoredProfile` | 孩子档案（名字、年级、头像、难度、顺序） | 数据库是唯一存储 |
| `StoredGrowth` | 成长档案：完整状态 `stateData`（JSON），另有经验、积分、徽章数、局数等列方便查询 | 数据库是唯一存储 |
| `StoredItemStats` | 每个孩子每个知识点的答题统计 | 数据库是唯一存储 |
| `StoredGame` | 每一局：输赢或中途退出、难度、题库和单元、题数、首答正确数、星级、用时、本局经验和积分 | 每局结束或中途退出时写入 |
| `StoredAnswer` | 每道题的第一次作答：知识点、题型、题面、正确答案、选了什么、对错、没来得及答、用时（毫秒） | 同上 |
| `StoredPack` / `StoredItem` | 题库包；能出题的知识点及所在题库/单元/课，`key` 与学习记录对应 | 题库 JSON，每次加载同步 |
| `StoredConfigFile` | 系统配置原文件 `pacing.json`、`badges.json`、`cosmetics.json` | `Resources/Config`，每次启动同步 |
| `StoredBadge` / `StoredCosmetic` | 校验通过的徽章、外观配置（外观特效参数在 `itemData`） | 同上 |
| `StoredSpeechClip` | 运行时生成的语音缓存索引：文本、音色、文件路径、大小 | 生成语音时写入；音频文件在 `LearnDefense/Speech/`，以文件为准 |

- 题库、系统配置的 JSON 仍是来源：家长导入题库、开发调参数都还是改 JSON，数据库里是同步过来的副本，只用来查询。
- 档案、成长档案、学习记录只存在数据库里。旧版 `profiles.json`、`growth/<档案id>.json`、`progress/<档案id>.json` 在第一次读取时自动导入，导入后改名为 `.json.migrated` 作备份。
- 数据库打不开时主页会提示；这次运行只读旧版 JSON（如果还在），改动不保存。
- 对局记录在开始闯关后才有：通关、失败、中途退出都记一局（中途退出不结算成长，经验和积分为空）。答题明细只记每道题的第一次作答；用时从这道题成为瞄准目标算起，包含暂停时间。App 在对局中被强制关掉时，这一局不会写入。
- 删除档案时，数据库里这个孩子的档案、成长档案、学习记录、对局和答题明细一起删除。
- 查询接口在 `LearnDatabase`：
  - 题库：`packs(grade:subject:)`、`items(containing:)`（某字/词出现在哪几课）、`items(key:)`
  - 个人：`profiles()`、`growthState(profileID:)`、`stats(profileID:)`、`mistakes(profileID:limit:)`（错得最多的知识点）
  - 对局：`games(profileID:since:limit:)`、`answers(gameID:)`、`answers(profileID:itemKey:)`、`kindAccuracy(profileID:since:)`（各题型正确率和平均用时）、`confusions(profileID:since:limit:)`（最常把哪个答案选成哪个）
  - 配置：`configFile(named:)`、`badges()`、`cosmetics(slot:)`
  - 语音缓存：`speechClip(key:voice:)`、`speechClipKeys(voice:)`

## 语音

朗读按文本找音频，按下面的顺序查找，都没有时用系统语音：

1. 题库自带：iPad「文件」App →「字灵守卫」→ `Packs/Audio/`，和题库 JSON 一起放进去
2. App 内置：`Packages/LearnKit/Sources/LearnGame/Resources/Speech/`
3. 用家长账号生成的缓存：「语音设置」里填了火山引擎（豆包语音）的 API Key 后，App 在后台为题库和提示语生成语音并缓存；新导入的题库下次启动时自动补齐
4. 云端语音（阿里云 OSS）：`SpeechRemoteConfig.baseURL` 配了地址时，App 启动后在后台下载完整 ZIP 语音包，校验 SHA-256 并解压验证后一次启用，之后离线也能播放。家长配了自己的账号且音色和云端不同时，优先用自己的音色生成

读到还没有音频的句子时先用系统语音，同时排到最前面下载或生成。

### 目录和命名

预先生成的语音（OSS、App 内置）按业务分类存放，文件名就是朗读的文本，根目录的 `manifest.json` 记录「文本 → 路径」：

```text
<音色目录>/
  manifest.json      {"version":1,"voice":"<音色>","clips":{"阳光不够":"game/提示语/阳光不够.mp3",…}}
  game/提示语/阳光不够.mp3        游戏提示语，另有 植物道具/、首领出场/、大招/
  packs/<题库id>_<题库标题>/<单元id>_<单元标题>/<课id>_<课标题>/震.mp3
```

- 同一句话只存一份，放在第一次出现的位置；英语题库不分课时直接放在单元目录下。
- 文件名里的 `/ \ : * ? " < > | # %` 换成 `_`，超过 40 字截断并加上 `~<key 前 8 位>`；同一目录下不区分大小写重名时也加这个后缀。
- `Packs/Audio/` 的备份和恢复只认平铺的文件，随题库分发时加 `--flat`，文件名用 `<文本key>.mp3`（key 为去掉首尾空白后文本的 SHA-256 前 32 位十六进制）。没有新版清单的目录 App 也按这个文件名查找，旧的语音包仍然能用。

### 生成

```bash
cd Packages/LearnKit
# 先看要读哪些句子、放在哪里（不调用接口）
swift run speech-pack --bundled --game-lines --list
# 生成内置题库和提示语到某个音色目录，再整个同步到 OSS
VOLC_TTS_API_KEY=<API Key> swift run speech-pack --bundled --game-lines --out <本地目录>/speech/v1/<音色目录>
# 随题库分发：生成到题库旁边的 Audio 目录
VOLC_TTS_API_KEY=<API Key> swift run speech-pack --packs <题库.json 或目录> --flat --out <题库目录>/Audio
```

- `--reuse <目录>`：旧版按 key 命名的音频（例如从 iPad 导出的运行时缓存 `<音色目录>`）有同一句话就直接复制，不调用接口；只复制时可以不填账号，但音色、语速的环境变量要和旧音频一致。
- 同一个输出目录只放一套音色：清单里记了音色，环境变量和它不一致时会停下。换音色就换一个输出目录（OSS 上对应新的音色目录）。
- 题库调整后某句话换了位置，会把原来的文件挪过去；清单里没有的音频会列出来，由人决定要不要删。

### 上传到 OSS

当前发布的语音目录为 `https://learn-games.oss-cn-hangzhou.aliyuncs.com/speech/v1/vv-jenny-r0/`，已配置到 `SpeechRemoteConfig.baseURL`。

整包备份下载：`https://learn-games.oss-cn-hangzhou.aliyuncs.com/speech/v1/vv-jenny-r0.zip`（21,798,798 字节，1,675 个 MP3 和 `manifest.json`）。ZIP 根目录直接包含 `manifest.json`、`game/` 和 `packs/`。
SHA-256：`eb19deaac4024c69a2eeb0f49948b51399f38f8b61c6dba158019126bfecec35`，校验文件地址为 ZIP 地址后加 `.sha256`。
标准配置使用 ZIP 整包下载：地址和 SHA-256 固定在 `SpeechRemoteConfig.archive`；完整安装后不重复请求网络。下载到临时文件，后台校验和解压，全部清单音频齐全后原子更新本地安装指针。失败或取消时保留旧缓存，可在语音设置中重试。自定义的无 ZIP 配置仍兼容逐文件下载。

不需要更新数据库结构或 `reader-preferences`：语音来源、语速、音量等保持原值；家长账号保留在 Keychain，`StoredSpeechClip` 仍只索引家长账号生成的缓存。云端包的安装状态保存在本地 `remote/installed.json`；用户选择系统语音时不下载。

发布新整包时使用新的版本路径，并一起更新代码中的 ZIP 地址和 SHA-256。不要只替换同地址 ZIP 的内容，否则旧客户端校验会拒绝它。

bucket 设为公共读（最好挂 CDN），App 里不放 AccessKey：

```bash
ossutil cp -r <本地目录>/speech oss://<bucket>/speech --update --meta "Content-Type:audio/mpeg"
```

然后把 `SpeechRemoteConfig.baseURL`（`LearnGame/Support/RemoteSpeech.swift`）设为音色目录的地址，末尾带 `/`，例如 `https://<bucket>.oss-cn-hangzhou.aliyuncs.com/speech/v1/<音色目录>/`。已上传的音频不要原地改内容（App 不会重新下载同一路径）；要整体重新生成就换版本目录（`v2`）。

### 说明

- 账号和音色用环境变量：`VOLC_TTS_API_KEY`（或旧版控制台的 `VOLC_TTS_APP_ID` + `VOLC_TTS_ACCESS_TOKEN`），可选 `VOLC_TTS_RESOURCE_ID`（默认 `seed-tts-2.0`）、`VOLC_TTS_SPEAKER`、`VOLC_TTS_ENGLISH_SPEAKER`、`VOLC_TTS_SPEECH_RATE`。
- 音色：中文和中英混合的句子用 `VOLC_TTS_SPEAKER`（默认 Vivi 2.0 `zh_female_vv_uranus_bigtts`），纯英文句子（英语题库的单词、句子）用 `VOLC_TTS_ENGLISH_SPEAKER`（默认英式女声 Charlotte `en_female_authoritative-british_uranus_bigtts`，与英语题库的英式音标一致）。可选的官方音色见 `TTSSettings.chineseVoices` / `englishVoices`。
- 已有的文件会跳过（`--force` 重新生成）。
- 要读的句子由出题规则决定（如生字读「晨，早晨的晨」），所以改了题目文字后要重新生成；文字没变就一直能命中。
- 豆包 2.0 音色不支持 SSML，多音字靠「字，词语的字」这种带词语的读法消歧。
