# 题库格式（schemaVersion 1）

题库是一个个 **JSON 文件**，每个文件叫一个「题库包」，通常对应一册课本（如「三年级上册 语文」）。

- 内置题库：`Packages/LearnKit/Sources/LearnCore/Resources/Packs/*.json`，随 App 一起打包。
- 自己导入：在 iPad「文件」App →「我的 iPad」→「字灵守卫」→ `Packs` 文件夹里放 JSON 文件，重启 App 即可读到。
  与内置题库 `id` 相同时，导入的覆盖内置的。

题库里放的是**知识点素材**（生字、词语、成语、古诗……），而不是一道道写死的题。
App 会根据素材和难度自动出题（看字选拼音、选字填空、成语补全、接下一句等），干扰项也自动生成。
只有特殊题目（如字义辨析）才需要用 `questions` 手写。

## 结构

```text
题库包 ContentPack
└── units 单元（多个）
    └── lessons 课（多个）
        ├── characters  生字
        ├── words       词语
        ├── idioms      成语
        ├── poems       古诗
        ├── pictures    图片词（幼儿园用）
        └── questions   手写选择题
```

课里的各个数组都可以省略，只填有的部分。

## 顶层字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `schemaVersion` | 是 | 固定为 `1` |
| `id` | 是 | 全局唯一，建议 `学科-年级-册-版本`，如 `chinese-g3-up-bubian` |
| `title` | 是 | 显示名称，如 `三年级上册 语文` |
| `subject` | 是 | `chinese` 语文 / `english` 英语 |
| `grade` | 是 | `k2` 中班、`k3` 大班、`g1`～`g6` 一～六年级 |
| `term` | 否 | `up` 上册 / `down` 下册 |
| `edition` | 否 | 教材版本，如 `部编版` |
| `units` | 是 | 单元列表 |

单元：`{ "id": "u1", "title": "第一单元", "theme": "academy", "lessons": [...] }`，课：`{ "id": "l1", "title": "1 大青树下的小学", ... }`。

单元的 `theme` 可省略，用来指定战场背景：

| `theme` | 背景 |
|---|---|
| `meadow` | 草地（适合动物） |
| `orchard` | 果园（适合水果、秋天） |
| `starry` | 星空（适合天空、夜晚） |
| `academy` | 书院 |

一局选了好几个单元时，用出现次数最多的主题。没写 `theme` 的，幼儿园默认用草地，小学默认用书院。
`id` 在同一个题库包内唯一即可。

## 素材类型

### 生字 `characters`

```json
{ "char": "晨", "pinyin": "chén", "words": ["早晨", "晨光"] }
```

- `pinyin` 用**带声调符号**的拼音（`chén`，不要写 `chen2`）；轻声不标调。
- `words` 是组词，可省略；有组词才会出「选字填空」题，也能在「看拼音选字」时给出提示。
- 出题：看字选拼音、看拼音选字、选字填空；幼儿园年级为「听音选字」。

### 词语 `words`

```json
{ "text": "早晨", "pinyin": "zǎo chen" }
```

拼音按字用空格分开。出题：看拼音选词语。

### 成语 `idioms`

```json
{ "text": "手舞足蹈", "pinyin": "shǒu wǔ zú dǎo", "meaning": "形容高兴到了极点。" }
```

出题：成语补全（随机挖掉一个字）。大招题优先从成语里出。

### 古诗 `poems`

```json
{ "title": "山行", "author": "杜牧", "dynasty": "唐",
  "lines": ["远上寒山石径斜", "白云生处有人家", "停车坐爱枫林晚", "霜叶红于二月花"] }
```

`lines` 按**句**拆分（逗号、句号处断开），不带标点。出题：给上一句，接下一句。

### 图片词 `pictures`（中班、大班）

```json
{ "text": "猫", "pinyin": "māo", "emoji": "🐱", "en": "cat" }
```

`emoji` 会自动换成对应的 3D 图片（来自 Microsoft Fluent Emoji）。App 里没有这张图时，就直接显示 emoji。
导入新题库后，运行 `python3 -I scripts/fetch-pictures.py`，把题库里用到但还没有的图补下载下来，再重新装一次 App。
出题方式：听读音选图片，孩子不用识字。答对后会弹出单词卡，上面有图、字和拼音。

### 手写选择题 `questions`

```json
{ "id": "q1", "prompt": "“霜叶红于二月花”中“于”的意思是？",
  "options": ["比", "在", "和"], "answer": "比", "explain": "霜叶比二月的花还要红。" }
```

`answer` 必须和 `options` 里的某一项完全一致。

## 学习记录

每个孩子的答题记录按素材记（如 `char:晨`、`idiom:手舞足蹈`、`poem:山行#0`），和具体题型无关。
所以同一个字，不管是看字选拼音答错，还是选字填空答错，都会进入错题本，之后更频繁地出现，
连续答对 2 次以上才从「待复习」里移出。修改题库素材的内容不会丢记录，但改了 `char`/`text`/诗题会被当成新素材。

## 本地数据库

App 用 SwiftData（底层 SQLite）在 Application Support 下的 `LearnDefense/learn.store` 存数据，代码见 `LearnCore/Storage/`：

| 表 | 内容 | 来源 |
|---|---|---|
| `StoredProfile` | 孩子档案（名字、年级、头像、难度、顺序） | 数据库是唯一存储 |
| `StoredGrowth` | 成长档案：完整状态 `stateData`（JSON），另有经验、积分、徽章数、局数等列方便查询 | 数据库是唯一存储 |
| `StoredItemStats` | 每个孩子每个知识点的答题统计 | 数据库是唯一存储 |
| `StoredPack` / `StoredItem` | 题库包；能出题的知识点及所在题库/单元/课，`key` 与学习记录对应 | 题库 JSON，每次加载同步 |
| `StoredConfigFile` | 系统配置原文件 `pacing.json`、`badges.json`、`cosmetics.json` | `Resources/Config`，每次启动同步 |
| `StoredBadge` / `StoredCosmetic` | 校验通过的徽章、外观配置（外观特效参数在 `itemData`） | 同上 |

- 题库、系统配置的 JSON 仍是来源：家长导入题库、开发调参数都还是改 JSON，数据库里是同步过来的副本，只用来查询。
- 档案、成长档案、学习记录只存在数据库里。旧版 `profiles.json`、`growth/<档案id>.json`、`progress/<档案id>.json` 在第一次读取时自动导入，导入后改名为 `.json.migrated` 作备份。
- 数据库打不开时主页会提示；这次运行只读旧版 JSON（如果还在），改动不保存。
- 删除档案时，数据库里这个孩子的档案、成长档案、学习记录一起删除。
- 查询接口在 `LearnDatabase`：
  - 题库：`packs(grade:subject:)`、`items(containing:)`（某字/词出现在哪几课）、`items(key:)`
  - 个人：`profiles()`、`growthState(profileID:)`、`stats(profileID:)`、`mistakes(profileID:limit:)`（错得最多的知识点）
  - 配置：`configFile(named:)`、`badges()`、`cosmetics(slot:)`
