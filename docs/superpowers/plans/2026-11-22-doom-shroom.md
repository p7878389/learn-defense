# 毁灭菇实现与验证计划

**目标：** 将 [毁灭菇设计](../../doom-shroom/README.md) 接入当前森林冒险，继续使用四卡、阳光和已有存档，不修改经典战斗规则。

**实现方式：** 当前会话直接执行；先编写失败测试，再实现纯规则，最后接入资源与界面。不自动提交、推送或合并。

## 规则与文件边界

- `LearnCore/Adventure/AdventureDoom.swift`：参数及可编码的蓄力、坑位状态。价格 125、蓄力 1 秒、冷却 50 秒、坑位 180 秒；范围按横纵格距归一化、半径 3.5 格。伤害初值 120：普通及重甲怪可被击败，标准第一关 160 生命的首领受到高额伤害而非必杀。
- `AdventureCatalog.swift`：增加冒险候选卡，默认卡组不变；四卡与至少一位射手继续由原规则约束。
- `AdventureBattle.swift`：合法落位才扣费；蓄力不阻挡、不被铲除；固定步长中结算一次伤害，发出纯展示事件，留下单格坑。波间仍推进计时；准备、暂停及结算不推进。准备阶段可预放，开战后蓄力。
- 新状态使用可选聚合字段，旧存档缺字段时按空状态读取；保留同局 ID、扣费与恢复规则。
- `AdventureScene.swift` 与新增 `AdventureDoomArtwork.swift`：通过 `FXLibrary` 加载本体、冲击与焦坑 `.sks`，仅展示事件和状态；恢复已有坑不重播伤害。倒计时为独立文字节点。
- `SeedPacketStrip.swift`：可选坐标空间和冷却参数，默认值保持经典调用兼容。`UnitSprites.portrait` 为新卡读取专用图。
- `AdventureView.swift`：保留当前布局与四卡；增加冷却 / 选中表达、取消和空格预览。修正冒险拖动使用共用卡栏 `gameLayout` 与冒险坐标空间不一致的问题。
- `scripts/build-doom-shroom.swift`：仅离线规范化透明原图、写入 `.sks` 和命名动作；维护源资源留在 `Resources/Effects`，运行时不拼装特效。

## 重点回归

1. 静态分析将场景 / 会话类标为 CRITICAL，包含跨模块导入；逐方法复核，再用完整回归和真实渲染覆盖。
2. 动画回调不得扣血；存档恢复不得再次爆炸已结算的焦坑，不得重复发奖。
3. 旧档不含毁灭菇字段也能继续，冷却、蓄力和坑位暂停时不走墙钟。
4. 已占用、场外、焦坑、冷却及阳光不足落点都不扣费；铲子不能提前消除坑位。
5. 相同草坪坐标同时驱动范围预览与伤害判定，横竖屏和拖动坐标保持一致。
