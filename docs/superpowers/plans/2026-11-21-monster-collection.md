# 怪物皮肤收藏与条件购买 Implementation Plan

> **For agentic workers:** 按任务逐项实现与验证；本会话不自动提交、合并或推送。

**Goal:** 将僵尸皮肤改为怪物皮肤，纳入已有怪物素材，支持积分、成就及累计条件解锁购买。

**Architecture:** 保留 enemySkin 存档槽位，新增独立怪物外观 ID，复用现有怪物素材与动画。条件写入 cosmetics.json，在 GrowthState 的状态、购买、装备和 loadout 中统一校验；EnemyNode 的外观与战斗 kind 分离。

**Tech Stack:** Swift、SwiftUI、SpriteKit、Swift Testing、JSON。

**Spec:** 本会话用户需求及已确认的「作为怪物皮肤，装备后替换外观」；收藏馆沿用已确认三栏布局和配色。

## Global Constraints

- 不改变关卡怪物池、血量、移动、攻击、掉落或首领行为；不新增依赖。
- 使用全部已有成品素材：6 种经典怪物、2 种森林小怪、10 种森林首领；没有成品的怪物不加入。
- 默认原版免费；购买不自动装备；条件达成只开放购买，不自动赠送付费外观。
- 保留现有存档字段和购买确认；新增字段可选，旧数据照常读取。
- 新增或重做特效使用 SKS；本任务复用已有角色素材，不重做战斗特效。

## Review Focus

1. 未达门槛即使积分足够也不得扣款或装备。
2. 条件达成后必须继续区分积分不足、可购买、已拥有、已装备。
3. 旧存档和无效外观 ID 安全回退，不丢失积分和其他装备。
4. 外观替换不改变原角色攻击、护甲、移动、死亡和首领判定；脱甲不能切回错误造型。
5. 缺攻击/死亡动画时可靠回退；预热、卡片和试穿采用同一外观映射。
