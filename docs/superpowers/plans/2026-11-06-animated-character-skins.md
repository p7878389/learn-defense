# 角色动画皮肤实施计划

**目标：** 基于项目原始透明序列帧，为豌豆射手与普通僵尸制作「软糖派对」「像素方块」两套可穿戴动画皮肤。

**架构：** 沿用收藏馆购买、装备、档案保存与 Loadout；增加两个角色槽位。用可重现的离线脚本逐帧加工原图，保持画布、裁切、pivot 和动画速度；SpriteRig 继续负责原有动作。皮肤限定豌豆射手 inkling 和普通僵尸 blob，其他角色保持辨识度。附加少量跟随角色的粒子。

**技术：** Swift / SpriteKit / SwiftUI、Python Pillow（只用于离线生成，不添加 App 依赖）。

**约束：** 不改攻击力、移动、答题、积分规则；默认原版；旧档案可读；缺失皮肤资源回退原版；不提交、不推送、不集成。依据后续建议，保留每帧剪影与射手主体绿色，用装备配件体现主题；普通攻击反馈保持绿色且短于 0.3 秒。

## 重点边界

动画切换时装扮不丢失；僵尸掉头/倒下和大招不恢复普通行走图；冰冻暂停；多节点共享纹理但独立动作；原版与其他植物/僵尸无变化。
