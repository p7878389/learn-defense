# SKS 动画设计 V2：翡翠彗星弹

## 设计依据与目标

使用 `game-feel` 的分层反馈、短促夸张、缓动与强度分级，以及 `create-game-assets` 的统一视觉规范、透明素材、实际比例验收流程。此版本接续资源化 MVP，先确定画面和时间线，再编辑 `.sks`，不以新增硬编码代替动画设计。

V1 在实际 1200×600 战场中有三个问题：命中主要是一圈细环、主色与草坪接近；飞行阶段只看到小圆弹；命中与击败缺乏强度递进。V2 要让“出膛—飞行—碰撞—退场”在正常速度下完整可读。

## 风格规范

- 视角：保持当前侧向塔防、左向右射击、原有植物/敌人比例。
- 材质：饱满魔法能量，中心有实质，外沿带柔光；有清楚的漫画切面和尖锐动势。
- 色彩：金白 `#FFF4B8` 为瞬时亮核，翡翠 `#6CFF8F` 为主体，青蓝 `#28DCD7` 为外沿，琥珀 `#FFBD4A` 为火花；深青轮廓帮助区分明亮草坪。
- 层级：弹体轮廓 > 短尾焰 > 稀疏碎点；命中瞬间亮核 > 斩痕 > 外环 > 碎屑。透明中心保留敌人轮廓。
- 普通攻击不增加全屏闪白和全场冻结；冲击感主要由局部形变、错峰动画和有方向的能量释放产生。
- 不改变答题、伤害、射速、能量或击杀结算。

## 一次攻击的时间线（以事件为起点）

| 阶段 | 节奏与画面 | 资源 |
| --- | --- | --- |
| 出膛 0–160 ms | 枪口金白亮核迅速张开，外侧小弧光向前甩出；先爆发后收束 | `PeaMuzzle.sks` + 命名动作 |
| 飞行，沿用现有 350–800 ms | 原弹体保留，后方叠一束约 2–3 个弹体长度的彗星尾；主体轻微呼吸，末端拉丝 | `PeaFlight.sks`，附着在弹体上 |
| 命中 0–45 ms | 局部白金撞击星压缩后弹开，命中中心明确 | `PeaImpact.sks/flash` |
| 命中 25–180 ms | 两条青金斩痕错角扫开，第一道冲击环快速扩张，第二道稍晚跟上 | `slashA/slashB/ring/echo` |
| 命中 60–430 ms | 8–12 颗有尖角的碎屑向右上散出；后半段失速下坠、快速淡出 | `debris` 发射器 |
| 受击约 240 ms | 本体更明确后仰，短停后带轻微过冲回正；仅改变视觉精灵角度 | `HitReaction` 动作 |
| 击败约 480 ms | 较大光环与短放射线突出击败，随后保留角色原倒地；稀疏金色余辉收尾 | `DefeatBloom.sks`，只在击败时触发 |

普通命中主范围约 90–120 pt，远比 V1 清楚但不覆盖整条路；中心不连续过曝。击败范围约 130–150 pt，主要差异是扩散层次与留白，不靠无限增加粒子。所有一次性命中资源在 0.48 秒内结束，兼容现有连发清理边界。

## 素材设计与交付

用 ImageGen 制作一张透明特效素材板，包含可拆分的：彗星尾焰、撞击星、能量弧、断裂环、尖角火花、击败光爆。使用同一色板、光照和轮廓语言。生成结果是美术源稿，经过裁切、统一透明边界、缩放和 alpha 检查后才能进入资源目录。无字、无背景、无角色、无烘焙棋盘格。

最终纹理以 128–256 px 为主，独立中心锚点，尾焰朝右且向左延伸。PNG RGBA，线性过滤。原始图与提示词留在设计目录，产物清单记录来源、切片范围、透明度和引擎验证结果。

## SKS 结构与代码边界

1. 延用 `FXLibrary`：节点布局、颜色、大小、粒子和动作时间全部保存在 `.sks` / `CombatActions.sks`。
2. 新增 `PeaMuzzle.sks`（独立短效果）、`PeaFlight.sks`（弹体子节点）、`DefeatBloom.sks`（击败独立效果）。
3. 在真正发射的现有回调中绑定枪口与飞行资源，连发等待阶段保持不可见；冰弹继续原路径。
4. `EnemyNode.defeat` 触发专用击败资源，原 `InkBurstEffect` 不扩成大爆炸，避免地雷、掉防具等调用者被误加重型反馈。
5. 添加的 Swift 只做资源选择、位置/方向绑定和生命周期；不在 Swift 拼贴特效层次或填写视觉时间线。
6. 飞行装饰附着弹体，随弹体清理；暂停由现有场景/资源暂停机制管理。

## 验收重点

正常尺寸能看到出膛闪光、完整弹体和短尾焰；命中爆点与敌人本体反应同步；普通命中和击败强度可区分；特效快速收束、仍能读清题目牌；相邻连发不变成常亮光团。性能收益不做未测承诺，iPad 真机观感和帧率仍需设备验收。
