# 首页（选择孩子）UI 设计稿

App 启动后的第一屏，对应代码里的 `ProfilesView`（「字灵守卫 / 今天谁来守护书本？」+ 孩子档案卡片）。尺寸和 `docs/ui-growth` 一致：11 寸 iPad 横屏 1194×834 pt，PNG 为 @2x。

| 文件 | 内容 |
|---|---|
| `01-stitch-首页-选择孩子.html` / `.png` | Stitch 生成的首页：游戏感 Logo、3 张孩子卡 + 「添加孩子」虚线卡、右上角「家长专区」、底部草坪（书架、向日葵、豌豆射手、举「字」牌的小僵尸） |
| `02-stitch-变体1-草坪战场.html` / `.png` | 变体 1：战场横截面。左边守卫书库，中间孩子卡站在草地台座上（上次玩的卡里直接有「派小虎出战！」按钮），右边栅栏外小僵尸。**右侧僵尸栏在 1194 宽度下被截掉一半**，落地要收窄或去掉两侧装饰 |
| `03-stitch-变体2-绘本书架.html` / `.png` | 变体 2：每个孩子是书架上的一本精装绘本（「小虎的英雄志」「朵朵的字灵记」），点「翻开绘本」进入；添加孩子是一本「未拆封新书」。宽屏才显示的两侧墨水瓶、打瞌睡僵尸在 iPad 上不出现 |
| `04-stitch-变体3-巨幕聚焦.html` / `.png` | 变体 3：上次玩的孩子放在中间大卡（160px 头像 + 72px 高的「开始守护小书屋！」按钮），其他孩子在左右两侧小卡，「添小新伙伴」缩成小按钮。孩子多于 3 个时需要改成真正的左右轮播 |

变体对比：变体 1 游戏感最强但最挤；变体 2 最安静、和「守护书本」主题最贴；变体 3 一步进入最快，适合大多时候只有一个孩子用的情况，但多了一层「先切换再开始」。

### 轮播规则

- 顺序：上次玩的孩子排第一个并默认居中，其余按最近游玩时间排；「添加小朋友」卡永远在最后。
- 切换：左右滑动，或点两侧「‹ ›」按钮，或直接点露出的侧卡；滑到第一张时左箭头隐藏，滑到添加卡时右箭头隐藏。
- 只有侧卡没有「开始守护」按钮，必须先把孩子滑到中间再开始，避免误点进别人的档案。
- 分页点数量 = 孩子数 + 1（「＋」）。孩子很多（比如超过 8 个）时，分页点只显示当前附近的几个，两端用小点表示还有。
- 只有 1 个孩子时：右边露出的就是添加卡。

### 新增儿童

- 入口有两个：轮播末尾的「添加小朋友」卡（05b），以及没有孩子时的空状态（07）。都打开同一个建卡面板（06）。
- 面板只要三项：头像、名字（必填，去掉首尾空格后不能为空，最多 6 个字）、年级。不收生日、手机号等信息。
- 「建好啦！」后关闭面板，新卡加到轮播里并滑到中间，带「🌱 新伙伴」角标和一次撒花动画（没出稿），孩子可以直接点「开始守护」。
- 「再想想」或右上角「✕」直接关闭，不保存。
- 编辑：卡片右上角「✏️」打开同一个面板（标题改为「修改小守卫」，按钮改为「保存」），面板底部放一个不显眼的「删除这个档案」，点了要二次确认（沿用现在「学习记录也会一起删除」的提示）。编辑和删除建议放进家长专区或加长按确认，避免孩子误删——这一版没出稿。
- 现在 `ProfilesView` 的「长按卡片编辑 / 删除」可以保留为备用入口。

### 稿件之间的不一致（落地时统一）

- 05b、07 是新生成的页面，Logo 字体、草坪颜色（深翠绿）和 05（浅草绿）不完全一样，以 05 为准。
- 05b 的侧卡布局（头像在左、文字在右）和 05 的侧卡（头像在上）不同，以 05 为准。
- 06 底部提示写「点击头像铅笔修改」，实际铅笔在卡片右上角，文案改为「点卡片右上角的 ✏️ 可以修改」。

## 设计要点

- 上次玩过的孩子卡片放大一点，加橙色描边和「上次是你」角标，孩子一眼能找到自己。
- 卡片：大头像 + 等级徽章（Lv.N）、名字、年级胶囊、一行状态（闯关次数 / 最近来过 / 读过多少字）。
- 「添加孩子」保留现有「长按卡片可以编辑」提示，对应现在的长按菜单（编辑 / 删除）。
- 「家长专区」按钮放右上角，灰白色，不抢孩子的注意力。

## 和现有功能的差距（落地前要决定）

- 等级徽章依赖成长系统（`docs/ui-growth`），没做成长系统前去掉或隐藏。
- 「上次是你」、「昨天来过」、「已闯关 N 次」、「已读 N 个字」需要记录最近游玩时间和统计，现有 `Profile` / `ProgressStore` 没有这些字段。
- 「家长专区」入口现在不存在（朗读语音设置稿 `docs/ui-tts` 里规划了家长专区）。
- 左上角「字灵守卫 iPad 版」标签和草坪中间的「答对汉字题…」提示条属于 Stitch 自己加的装饰，可去掉。
- 头像用的是 emoji 字体；App 里实际是 Fluent Emoji 3D 图片（`PictureView`）。

## 代码实现（分支 `feature/首页轮播`）

按 05~07 实现，文件在 `Packages/LearnKit/Sources/LearnGame/Views/`：

| 文件 | 内容 |
|---|---|
| `ProfilesView.swift` | 首页：左右滑动轮播（`ScrollView` + `scrollTargetBehavior(.viewAligned)` + `scrollPosition`），两侧 64pt 箭头、分页点（可点）、空状态；从主页返回时重新排序并停在上次玩的孩子上 |
| `HomeCarousel.swift` | 孩子卡、添加卡、空状态卡、Logo、分页点、底部草坪 |
| `ProfileEditor.swift` | 建卡 / 修改面板（06），全屏半透明遮罩 + 大面板；修改时底部有「删除这个档案」（二次确认）。主页的「编辑档案」也改用这个面板，但不带删除 |

卡片数据都来自已有记录，没有改数据库结构：

- 等级：成长档案 `GrowthStore.level`
- 闯关次数：成长统计 `gamesPlayed`（打完的局数，不含中途退出）
- 「上次是你」、排序、连续天数、「N 天没来」：对局记录 `StoredGame.startedAt`，计算在 `LearnCore/Progress/PlayActivity.swift`（含中途退出的局）。对局记录是 SwiftData 版本之后才有的，更早玩过的孩子在再玩一局之前没有这些信息

和设计稿的差异：

- 删除档案从「长按卡片」改到 ✏️ 面板底部；长按菜单去掉了。
- 「家长专区」现在打开的是原来的朗读语音设置（目前唯一的家长设置），没有加锁。
- 草坪上的向日葵用 Fluent 🌻 图片（植物素材里没有向日葵），豌豆射手和僵尸用战斗序列帧的第一帧。
- 建好后的撒花动画没做；新卡会停在中间并带「🌱 新伙伴」角标。
- 孩子很多时分页点全部显示，没有做只显示附近几个。
