# 怪物皮肤收藏

收藏馆「怪物皮肤」提供默认原版和 18 种已完成怪物外观，左侧可筛选全部、经典怪物、森林怪物。卡片与试穿复用现有真实素材。

## 装备范围

怪物外观购买即启用，无需装备。每局从当前孩子已拥有且满足解锁条件的怪物构建展示池，独立打乱轮换，每轮用完所有外观，多个外观时避免相邻重复。没有已解锁且已购买的外观时只显示默认普通怪物。森林路径模式维持独立渲染，不受展示池影响。

`EnemyNode.kind`、血量、移动策略、攻击、首领标记、奖励、掉落、出怪计划均保留原值。只切换渲染序列帧；受伤不会把选中的怪物外观切回原怪物的脱甲素材。缺失或无效资源回退原版。默认原版卡用于说明没有已购外观时显示默认普通怪物的规则，不提供装备或重置按钮。

全部配置位于 `Packages/LearnKit/Sources/LearnCore/Resources/Config/cosmetics.json`。

- `enemyAppearance`：已有 `EnemyKind.id`，仅允许怪物皮肤槽位。
- `unlockBadge`：已获得徽章 ID，目录校验会拒绝不存在的徽章。
- `unlockStat` 与 `unlockCount`：累计统计项及正数门槛，必须成对设置。

未达条件、积分不足均不扣款；重复购买不扣款。怪物皮肤买后自动加入展示池，射手皮肤沿用原装备行为。所有条件由模型校验，UI 显示门槛与进度。

新字段均可选，旧存档不改结构。旧装备及退役皮肤兼容保持原样。新增特效仍遵守项目 SKS 约定，本次未新增或重做战斗特效。

## 购买语音

购买提示统一由 `SpeechText.Line.purchaseSuccess` 生成，并加入 `SpeechText.purchaseLines` 与豆包语音目录。进入收藏馆优先准备这些语音。购买成功时豆包模式最多等待 8 秒下载/生成并缓存，失败兜底系统朗读；用户停止或新的打断朗读会取消等待。

豆包凭据留在 iPad Keychain。可通过 `speech-pack --collection-lines --out <目录>` 仅生成购买语音（当前 25 句），无需重新生成整套题库。线上已有 ZIP 不会凭空包含新增文案；设备需联网并有可用豆包配置，或开发者后续更新已生成音频包。

旧存档的单个 `enemySkin` 装备引用会清理，已购记录保留并用于自动展示池。怪物抽样不使用出怪、掉落和题目的随机数生成器。

设备验证：2026-11-21 已在测试 iPad 安装修复版并启动。购买提示语缓存由更新前 0/25 变为 25/25，均为非空 MP3 文件；未导出豆包密钥。351 项 Swift 测试、真机构建通过。

## 出场名称一致性

怪物实际外观确定后，由场景回调会话播放出场语音。首领名称、预警条和语音共用实际渲染名称；内部 kind 仍用于关卡数值。没有已解锁且已购买的外观时，仅使用默认普通怪物展示，不再直接显示关卡计划中尚未解锁的怪物造型。全部 18 种显示名称都进入出场语音预生成清单。收藏卡去掉已拥有文案，品质标签移至底部中央。
