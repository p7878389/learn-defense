# 成长系统 UI 设计稿（儿童向）

对应成长系统方案里的「等级 / 积分 / 徽章 / 外观」四块界面。尺寸按 11 寸 iPad 横屏 1194×834 pt 绘制，PNG 为 @2x（2388×1668）。

## 主稿

| 文件 | 界面 | 让孩子有成就感的设计点 |
|---|---|---|
| `01-档案主页` | 档案主页（视觉稿） | 头像外圈等级勋章 + 「Lv.5 小小守卫」丝带牌；粗经验条末端放礼物盒，写明「再得 70 经验升到 Lv.6，解锁彩纸礼花」；金色积分牌；收藏馆、徽章墙两张大入口卡 |
| `02-结算升级` | 通关 + 升级 | 三颗星弹出，每颗星下写清楚怎么拿到的；经验 / 积分两块大数字；升级时右栏显示「升级啦！」、这一级解锁的外观（可以去收藏馆买）、新徽章 |
| `03-收藏馆` | 子弹外观 | 顶部草坪预览舞台先看效果；卡片四种状态：装备 / 使用中 / 🪙 购买 / 🔒 Lv.N 解锁（带「还差 N 级」进度） |
| `04-徽章墙` | 徽章墙 | 已得徽章是彩色圆形奖章 + 丝带 + 日期；没得到的是灰色奖章，但保留进度条（如 63/100），快完成的标「还差 3 次！」；右侧详情和「下一个目标」 |

## 和方案、代码对齐的规则

- 数值：Lv.5→6 需要 460 经验，Lv.6→7 需要 560；星级沿用 `GameSession.stars`（通关 1 星，首答正确率 ≥70% 2 星，≥90% 且没丢心 3 星）；徽章只奖励积分。
- 外观：等级到了只是「解锁」，价格大于 0 的要用积分买（如彩纸礼花 Lv.6 解锁、🪙150）；价格为 0 的才是升级直接送（如星星飞散、金星弹）。
- 结算页保留现有的「记一记」错题列表。
- 积分牌上不放「＋」号，避免看起来像能充值（方案规定没有真钱入口）。

**设计稿里有、但第一阶段不实现的部分**：按原方案开发，这些先不做，设计稿保留不改，后面再加：

- 主页「今日小目标」三张任务卡、「🔥 连续 3 天」火苗牌
- 主页、徽章墙上的「小小守卫」等级称号
- 收藏馆底部「坚持打卡奖励更多」
