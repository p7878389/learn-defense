# 经典模式地图

`woodland-grass.png` 为“古树秘境”美术，用于林间草坪战场与地图缩略图。由内置 ImageGen 基于原地图重新设计，再收窄左侧树干与树根，为第一列角色留出空间。包含古树、藤蔓遗迹、暖光林隙和苔藓草地；未引入外部素材。

原画尺寸为 1774×887，无透明通道。沿用 `BattleMapArtwork` 的分带校准与右侧镜像延伸，输出 1200×600 战场；五行九列种植几何与战斗规则不变。图片提示词、SHA-256 与验证状态见 `docs/maps/woodland-grass-prompt.txt` 和 `docs/maps/asset-manifest.json`。
